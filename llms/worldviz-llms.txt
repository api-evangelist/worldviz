# WorldViz

> WorldViz LLC (Santa Barbara, California) builds virtual reality software and hardware
> systems for academic research, training and simulation. Its developer surface is Vizard —
> a Python 3.13 VR development toolkit and IDE installed on Windows — together with the
> SightLab VR Pro experiment-authoring plugin, the Vizible collaboration product, PPT motion
> tracking, and the PRISM projection/simulation room systems. WorldViz publishes no web API:
> there is no OpenAPI, AsyncAPI, GraphQL schema, MCP server or agent card anywhere on its
> hosts. What it does publish is a large, crawlable Python command reference — 1,182
> individual command pages across 36 modules — which is the machine-readable-adjacent
> contract for the toolkit.

## Developer surface — Vizard

- [Vizard documentation](https://docs.worldviz.com/vizard/latest/): Vizard 8 manual. Current
  documented build 8.3.1.
- [Vizard command index](https://docs.worldviz.com/vizard/latest/commands/commandIndex.htm):
  The Python API reference. 1,182 command pages across modules including node3d (319), viz
  (224), vizact (56), window (49), transform (49), link (46), animationpath (44), viztask
  (36), texture (32), multimedia (25), vizmat (22), viewpoint (22), vizcave (21), viznet,
  vizshape, vizfx, hand, sensor, scene and physics.
- [Installation](https://docs.worldviz.com/vizard/latest/Installation.htm): Getting started.
- [What's New in Vizard 8](https://docs.worldviz.com/vizard/latest/highlights.htm): Dated
  release notes — 8.3 (2025-12-05), 8.2 (2025-02-04), 8.1 (2024-12-23), 8.0 (2024-11-11).
- [Upgrade guide](https://docs.worldviz.com/vizard/latest/Upgrade_guide.htm): Vizard 7 to 8
  breaking changes — Python 3.8 to 3.13, Windows 10 minimum, PIL/Pillow unbundled.
- [Package Manager](https://docs.worldviz.com/vizard/latest/Package_Manager.htm): Vizard's
  GUI pip client for installing PyPI packages into its bundled Python. Consumes PyPI; does
  not publish to it.
- [Licence agreement](https://docs.worldviz.com/vizard/latest/Legal_stuff.htm): Vizard end
  user licence agreement, published in full.

## What WorldViz does not publish

Probed 2026-09-04 and confirmed absent, so an agent does not spend calls looking:

- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI or Protobuf/WSDL contract. /openapi.json,
  /openapi.yaml, /swagger.json, /v1/openapi.json, /api-docs, /redoc and /graphql all return
  404 on worldviz.com, www.worldviz.com and docs.worldviz.com.
- No /.well-known/ documents on any of eight WorldViz hosts — no security.txt, api-catalog,
  openid-configuration, oauth-authorization-server, ai-plugin.json, agent-card.json or
  agent.json.
- No A2A agent card and no MCP server.
- No llms.txt of WorldViz's own (this file is ours, not theirs).
- No status page (status.worldviz.com does not resolve), no SLA, no deprecation policy.
- No privacy policy at any conventional path on worldviz.com.
- No first-party package in npm, PyPI, Maven Central, NuGet, RubyGems, Packagist, crates.io
  or pkg.go.dev. The PyPI package "vizard" and the npm package "vizard" belong to unrelated
  third parties and must not be attributed to WorldViz.
